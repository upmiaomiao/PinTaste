# 局部裁剪与独立复核

当见微观测、已完成的视觉复核或用户框选指出某个细节不确定，且已有可信的原图像素框时使用。主模型组织工具调用，不自行读取像素或猜一个框来代替专业判读。

同一影像存在多个尚未排除的候选时，按各自的原图像素窗分别建立待核查项，不得因为已经执行过一次裁剪而漏掉第二处。逐处记录来源、原候选标签、已完成的判读和失败情况；有限预算未覆盖的候选应明确列为未完成，不能当作已排除。裁剪后仍不确定时，先查任务时段附近实际存在且可取得的历史影像，再根据具体的地表光谱或散射问题补充适用的多光谱或SAR证据；不得为凑流程下载全部模态。

- 调用 `wuyu_crop_image`，只传当前用户拥有的已登记 `asset_id` 和原始整数 `pixel_box=[left,top,right,bottom]`。右侧和下侧边界不包含在窗口中；坐标基于父图原始像素。可用 `padding` 加入已有周边上下文，默认0.15，范围0至1。不能传文件路径或URL。
- 工具返回局部图 `id`、`derived_from_asset_id`、`source_pixel_window` 和原图哈希。它仅提取已有像素，不插值，不增加原生分辨率，也不增加独立图源或新的时间观测。
- 用 `wuyu_submit` 将返回局部图和父图共同放入 `asset_ids`，保留任务原范围、实际日期及现有不确定性，要求见微核对具体目标形态、纹理、边界和竞争解释。使用 `wuyu_wait_run` 等待实际结果后再汇总。
- 原图的建筑、屋顶、正常备料或土方可能误识别成固废，应结合已配置的同图复核角色核查；被明确排除的误报不复活。局部缺少原生像素、遮挡或模糊时，裁剪不能补出细节，应按任务补取更适用来源、日期或现场资料。
- 没有可信像素框时，先让见微返回可定位的候选或请用户框选，不编造像素定位。科学多光谱、SAR和高光谱数值数据使用对应原生窗口工具，不用这个光学裁图工具替代。

向用户说明“我截取了原图中这处局部，接下来交给见微结合全景再确认”。只有专业判读实际返回后才说明复核结果；不能把裁剪完成称为疑点确认。
