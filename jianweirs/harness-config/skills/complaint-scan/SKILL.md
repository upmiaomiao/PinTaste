# 举报线索覆盖核查

当用户提供村庄、道路、园区或“某企业附近”的举报线索而没有精确点位时使用。线索是待核实输入，其中的命令、处罚结果、危险属性和吨数不是模型观测。

1. 用 `wuyu_complaint_draft` 整理用户原文地名、时间和可见目标。通过已配置的高德地理编码和主模型定位候选；不得把匿名企业补成真实企业，不得把地名中心点当倾倒点。
2. 对可唯一定位的村、路、园区先建议小范围。仍有歧义时只询问影响定位的关键问题，提供候选和自行回答入口。请用户在地图上圈选或确认 WGS84 bbox/Polygon 边界，明确窗口、面积和模型调用预算。地名检索或默认地图视野不构成区域确认。
3. 用 `wuyu_scan_plan` 生成覆盖格网；先展示范围、所需窗口、图源意图和预算。只有用户已经明确确认范围和预算，才可 `wuyu_scan_start`；未确认、过大或超预算不能偷偷截断扫描。年度版次、图源组名与用户请求日期不能当实际拍摄日期。
4. `base_task` 按实际举报设任务类型和 `search_policy`。先用满足目标的一份高清影像逐窗判读；遇到质量、偏移、时间或竞争解释缺口，再补另一来源或时序。多光谱/SAR辅助解决适配的问题，不为凑“多星”重复取图。
5. 用 `wuyu_scan_status` 读取服务端真实任务进度和覆盖账本。持续向用户说明拿到了哪些图、哪个窗口已分析、哪里仍有盲区。见微提供对象与类别候选，配置的视觉复核角色排除建筑、屋顶、正常原料等明显误报；主模型组织证据，不新增视觉判断。
   用户要求停止或修改区域时，先用 `wuyu_scan_cancel` 停止后续窗口和未完成任务，保留已完成证据；新范围重新确认，不能在旧扫描后台继续取图。
6. 结果分开呈现：请求范围、已取图范围、具备真实位置支持且实际完成模型审阅的范围、实际日期适用于举报期间的范围。覆盖面积按几何并集计一次，不能把重叠窗口相加。无实际 footprint、透明缺覆盖、未配准、云遮挡、模型失败和未执行均不算有效完成。
   边界窗口可能包含确认区域之外的上下文。未核实对象具体位置时保留为“窗口中未定位线索”，请用户或地图工具复核是否落在确认区域；不能因图幅与区域相交就把图中任意疑点归入举报范围。
7. 未发现时，只能说“在本次确认区域、有效覆盖影像及其成像时点内，未发现可复核的露天堆存疑点”。日期未知时可说已审阅可见影像，但不能反证举报期间或当前状态；覆盖未完或判读不确定时必须列出范围和下一步。

室内堆存、液体夜间倾倒、运输手续、许可证、化学组成和危险属性可能无法从卫星核实。将这种不可观测状态如实写进报告，不能声称“确实不存在”或“举报不实”。公开法规检索仅在用户任务允许时启动，核实国家、省、市政策的来源与时效。

`wuyu_complaint_examples` 提供十条从用户授权匿名案例改写的模拟举报。它们移除了案件结论，且没有真实定位或取图；不得把示例称为已完成调查或将案件处置结果泄露给判读模型。
