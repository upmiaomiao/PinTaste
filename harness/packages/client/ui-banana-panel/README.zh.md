# @deepseek-ai/dsh-client-ui-banana-panel

[English](README.md) | 中文

每个已认证账号与会话由Host维护一份当前需求，记录字段值、来源、版本和已绑定项目的应用状态。未指定的任务、页数、内容语言和输出保持自动；用户明确提出的要求在当前文稿中持续有效，普通“这次”措辞也不会只作用于一条消息。第四版HTTP客户端读取当前记录，旧响应字段只是兼容投影，旧客户端保存时保留无法表达的字段。右侧读取同一记录，不维护第二份可编辑配置。保存需求不授予模型、搜索、模板、页图审核、费用或删除权限。

## 概览

工作对话负责需求和制作决策。右侧详情列展示推荐设计、私人上传、生成页面及真实导出，普通用户无需配置模型。

## 使用面板

模板选择阶段的真实工具结果提供对话按钮。面板支持按任务推荐、至少四页中性模板预览、放大、浏览库及独立的私人模板上传。保存的个人设计明确标为私人，实际页数可以较少。选择文件不会自动上传或生成；服务端真实确认后只将继续制作的文字放入草稿，保留原文字与附件。

实际页面图片先于可编辑描摹展示。确认草稿绑定确切修订和图片版本，改页后须重新确认。全原生导出成功后提供明确的“保存为我的模板”，图片版和混合版不具备此资格。

工作语音共用平台 ASR 设置与工作权限。转写追加到当前未发送草稿，不自动发送；离开、取消及迟到回调会释放录音资源，输入忙时仍保留可恢复的转写。

项目详情提供材料容量和“删除材料”。项目所有者明确确认后可永久删除上传材料，上传或项目任务进行中暂不允许。删除清除原文件、解析预览和当前项目阅读草稿及共享缓存，保留已生成 PPT 和对话历史；文件清理失败会阻止后续处理并提供重试。输入框已完成的材料行和未发送附件通知同步为服务端剩余材料，删除不会发送对话消息。单文件须小于 50 MiB、项目最多 50 份；未确认选择可替换，发送成功后保留项目材料并释放本地 File 与已准备的发送数据。

服务端还限制累计上传字节和保留的提取数据，并在阅读前检查容量。超限时需减少选用材料或删除不需要的文件，不把截断文档标成完整。默认值、归属检查及验证范围见[材料容量与删除决策](../../../.agents/notes/implemented/feature/2026-11-05-ppt-material-capacity-and-deletion.zh.md)。

## 归属和失败处理

插槽注入负责 HTTP、输入操作和生命周期，组件只接收类型化回调与快照钩子。模板 URL 和工作流决策在通信边界校验，失败或过期请求不能确认其他项目或版本。个人模板预览按账号隔离，系统记忆管理控件位于其他管理端，普通用户不可访问。

仅页数或内容语言变化时，系统保留精确材料阅读输入与证据上下文供重新规划，同时撤销受影响草稿的确认。批次中一份材料解析失败时保留其他成功文件，不完整覆盖仍明确显示，并要求修复或明确排除。失败规划响应会提供诊断，不会悄悄重复付费请求。原文件和已生成输出保留在原对话中。本项不提供原生解析进程硬隔离或全面高负载恢复。

## 模型体验

模型通过现有 MCP 工具结果接收真实工作流决策。打开面板不等于确认模板、生图或授权描摹；模型请求无效操作时，后端仍执行硬性门槛。设计偏好由服务端冻结，不充当项目证据或可执行技能。

## 开发说明

模板与审核、语音、真实通信结构及任务卡片测试覆盖这些边界。构建时的公开端点使用 AI 域名，模型凭据保留在服务端。参阅[决策记录](../../../.agents/notes/proposed/feature/2026-10-21-wuyu-design-review-memory.md)。

工作进度优先显示新重试任务，旧未完成草稿不覆盖当前任务状态。失败对话行保留历史含义，并引导查看最新工作详情。私人上传视图可见时自动刷新解析，最多120秒或30次读取；解析完成却无预览是明确终态。库模板确认要求4张已加载预览及足够来源参考，私人模板要求1张。草稿失效会提示下一步，不自动启动模型处理（[决策](../../../.agents/notes/implemented/bug-fix/2026-11-05-ppt-work-state-and-template-progress.zh.md)）。

输入框在联网与深度探索旁提供只读“当前需求”按钮，修改通过对话表达。打开此视图或本地需求工具成功完成时重新读取权威记录；成功和失败行均保留“查看当前需求”，不把工具返回值复制成另一份配置。主附件按钮直接选择资料，模板与Logo用途保留在可选二级菜单。选文件和上传准备均不发送对话消息。确认页面图片后，交付面板提供图片PPTX、可编辑PPTX、PDF和图片ZIP；原生转换仍使用单独的明确请求与恢复操作。

全部模板包括所属账号已完成的上传和收藏设计，并提供来源筛选。跨项目复用上传模板会明确创建独立副本；公共浏览不暴露其他账号私人上传（[决策](../../../.agents/notes/implemented/bug-fix/2026-11-05-private-upload-template-library.zh.md)）。

## 对话式任务入口

用户直接描述目标或上传资料，无需先选择新建/重排、页数或内容语言。首页解释对话入口，可选“当前需求”视图区分明确选择、继承值、建议和未确定字段；已有资料任务称为“基于资料创作”。上传不会锁定对话任务身份，变更任务保留原文件和历史输出；尚未应用或存在冲突的项目投影须先处理才能执行。

模型通过get_presentation_requirements读取需求，经update_presentation_requirements提交已校验的字段。更新须引用最近已接受的人类消息，或其原生ask_user_question回答的已核验回执ID，并逐字引用读取工具返回的非空证据。回执严格配对内建调用与成功结果，核对问题ID和所选选项，仅保留用户选择标签或输入原文；上传文本、任意工具和插件上下文不能提供此身份。Host串行投影到归属项目的brief，版本一致前拒绝后续规划或生成；未确定页数不能静默使用12页。现有确认仍为执行依据（[决策](../../../.agents/notes/implemented/feature/2026-11-06-conversation-first-requirements.zh.md)）。

没有保留来源的研究失败或暂停时，提供原项目“改用已上传材料”恢复按钮。真实点击读取最新研究与工作流版本，拒绝活动任务或已保留报告，再通过既有用户确认操作选择材料。文件和项目保留；恢复不发送消息或生成PPT。已有来源的研究需要单独决定保留和补充方式。联网和深度搜索在当前挂载会话中跨消息保持选中，每条消息仍分别授权；刷新后恢复已保存选择。详见[恢复决策](../../../.agents/notes/implemented/bug-fix/2026-11-06-ppt-recovery-and-search-mode.zh.md)。


联网、深度搜索或关闭随当前对话的PPT偏好保存，刷新和新浏览器上下文可恢复。选择只保存偏好，不启动搜索；每次明确发送仍通过现有意图机制。旧偏好客户端保存时保留此字段。


公共模板分类区分整套PPT、工艺流程图、技术路线、摘要图和论文方法图。单图参考明确范围，须实际加载预览，只用于专业单图或1页内容；整套确认仍需5张真实正文参考。两处工作模板浏览入口均提供“全部”和五类按钮；分类、来源与搜索共同筛选，24条分页保留条件，切换分类回到第一页（[决策](../../../.agents/notes/implemented/bug-fix/2026-11-06-clickable-template-categories.zh.md)）。

对话将输出格式保留为交付偏好。工作流先交付图片时，不替换该偏好，也不使已同步的规划需求失效。读取归属工作流后，只有全部投影需求及配置标记一致，并通过版本与绑定检查，才能确认原有待同步状态。失败后明确点击“查看当前需求”会重新读取权威记录，历史工具失败仍保留原意。读取与确认不会生成页面，也不批准可编辑转换（[决策](../../../.agents/notes/implemented/bug-fix/2026-11-07-ppt-requirements-delivery-recovery.zh.md)）。

一页需求在同一次owner事务内解析为pages类型，包括继承的整套类型；非法组合不保存半份要求或回执。恢复保留已读证据：规划反馈改变内容计划，来源身份或阅读目标改变时则要求重新匹配reader上下文。已知坏计划缓存等待具体用户反馈，不再推荐原样重复付费动作。安全工作流错误明确所需审核、刷新版本或额度步骤，不暴露后台错误正文，也不启动工作（[决策](../../../.agents/notes/implemented/bug-fix/2026-11-07-ppt-project-recovery.zh.md)）。

需求读取工具返回最新已接受的用户消息标识，以及最多2000个UTF-16单元且不截断代理对的原文字面摘录。更新必须引用该用户消息或已核验原生问题回答的逐字子串；助手、任意工具和材料或插件结果不能充当用户来源。最新选项回答未保存或页数未定时，Host在创建项目或启动研究前拒绝执行；先完整保存已确认范围，未改变字段也可用有效空更新记录回执。保存不授予搜索、生成或费用授权；工作流请求编号仍必须为有效UUID。来源、版本冲突与格式失败明确说明本次修改未保存；固定的待投影错误说明需求已保存但未同步；未知错误要求重新读取当前需求，不猜测保存结果（[决策](../../../.agents/notes/implemented/bug-fix/2026-11-08-ppt-requirements-source-feedback.zh.md)）。

研究完成后需求变化时，“当前需求”可提供已接受且非部分报告的明确复用入口。项目所有者核对适用性后点击“沿用已有研究资料”；操作重新读取当前版本，拒绝活动或未知任务，并保留原有UI研究确认边界。独立的范围回执保留原问题、研究签名、报告、已选来源材料、费用、缓存和产物；沿用不补齐新范围，不搜索、不创建任务或生成页面。已删除、排除或改变的来源材料及部分报告不会被静默恢复或接纳。
