# Agent Note: 对话维护PPT当前需求

Status: implemented

[English](2026-11-06-conversation-first-requirements.md) | 中文

## 问题

对话设置与项目brief分别可编辑时，两者可能不一致。前置选择还要求用户在表达目标前确定任务、页数与语言。过度失效与整批失败处理可能舍弃可用准备成果，或让对话看起来无法继续。

## 决策

已认证Session的Host拥有唯一当前需求记录，包含字段值、逐字段来源、版本、项目绑定及投影状态。自动值保持未确定，普通“这次”要求在当前文稿中持续有效。既有HTTP响应是该记录的投影，不构成另一份可编辑数据；旧客户端保存时保留无法表达的字段。无需批量重写历史数据或迁移SQL结构。

本地需求工具读取记录，提交已校验补丁时引用最近已接受的人类消息ID及该消息中的精确非空证据片段。源资料和插件消息不能充当人类更新依据。已保存补丁串行投影到归属项目的brief，版本应用前规划与生成等待；未确定页数不能落入12页默认。模板、研究、费用、最终页图与删除检查分别保留。

首页与附件入口支持直接对话和资料接入，上传不锁定任务。右侧摘要和实际项目详情应用展示同一Host记录及来源，工作流结果不能替换该记录。Host上下文通知在不导航iframe、不丢失反馈的情况下刷新需求。[运行产物生成器](../../../../../work-agent/tools/conversation-requirements-ui.cjs)针对SHA锁定的实际HTML修改，不重建较旧的authoring树。

仅页数或语言变化时，重新规划保留精确材料阅读输入和证据上下文，并要求重新审核受影响草稿；其他实质内容变化仍按输入依赖失效。批次解析逐份记录错误并保留成功成员。失败规划缓存给出恢复诊断，不自动重复付费操作。任务变化在原对话保留源文件与历史输出，待处理冲突不授予执行权限。

## 考虑过的替代方案

**保留分别可编辑的选择器与项目字段。** 多个所有者可能给出不同的生效要求。

**把任务状态和审批放入需求记录。** 偏好修改会被误认为执行或重试授权。

**任意失败后重建整个项目。** 丢弃可用准备成果，也无法说明需要处理的输入或步骤。

## 影响

需求表达当前目标，任务及其不可变输入版本描述执行。更新要求不批准模板、搜索、生图、原生转换或删除；材料、参考、额度、版本及归属校验仍为执行依据。服务或投影需要修复时，用户仍可继续讨论需求。

定向验证覆盖需求持久化与兼容、已接受消息证据、投影门槛、页数/语言缓存复用、批次部分失败和两个浏览器入口。原生解析硬隔离、全面高负载恢复及任何模型失败都能自动完成的保证均不在本项范围。完整框架类型/GUI与付费端到端生成需要独立证据。
