# Agent Note: 保存对话联网选择

Status: implemented

[English](2026-11-06-conversation-search-persistence.md) | 中文

## 问题

只保留在运行期控制器中的联网选择会在刷新时丢失，也可能与恢复的对话不一致。

## 决策

由现有对话偏好保存search_mode，取值off、web或deep。输入框直接读取该拥有者，点击只保存、不启动检索。发送先等待偏好确认，再把实际选择交给现有搜索修饰器。重排禁用研究，但不抹掉保存的新建任务偏好。

第三版HTTP返回六字段，第二版保持五字段，旧版保持三字段；保存时缺search_mode保留存量值。旧记录读取时默认为off，不做迁移。

## 考虑过的替代方案

**只用本地存储。** 无法在新上下文或另一设备恢复，且脱离账号拥有的对话。

**复用搜索同意。** 持久选择不是重复研究指令；本次保持原有逐次发送意图机制。

## 影响

联网和深度模式仍互斥。保存失败阻止发送并提示错误，并发写仍检查版本。不改SQL结构或批量重写业务记录。只回退前端时必须保留六字段兼容Host reader。零调用检查覆盖真实HTTP投影、旧保存、对话隔离与控制器恢复；双语组装页面验证刷新行为。
