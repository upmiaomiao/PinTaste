# Agent Note: 分类公共图参考模板

Status: implemented

[English](2026-11-06-public-figure-template-categories.md) | 中文

## 问题

单张流程图或研究示意图不能提供5张真实正文参考。按整套模板导入会造成条目可见却不可用，缺少分类也会使推荐偏离实际任务。

## 决策

明确的管理员文件导入先验证PNG字节、哈希、路径和唯一标识，再发布已批准参考图。本批包含66张用户素材和12套既有公共系统模板，连续编号命名。图分类是独立筛选和推荐依据，不混同当前研究主题。

受信任catalog中的single_image范围只对专业单图或1页内容放行一张已实际加载的预览；普通整套仍保留5张不同的真实正文参考。界面读取真实范围，确认与生成分开，分页保留分类。MCP暴露相同分类与范围；旧私人六维标签缺新增分类时归一为空列表。

## 考虑过的替代方案

**复制一张图凑5页。** 伪造参考覆盖，隐藏素材限制。

**只列图而不支持确认。** 导入条目仍不可用。

**再调用模型重做导入分类。** 用户已提供分类目录，无需重复付费；本次记录明确的目录分类。

## 影响

本地原件保留，技术PNG预览长边最多4096。仅复制正式站已审核公共系统参考，不读取私人上传或修改正式业务。模板内容仅作视觉参考，不作本项目事实证据。导入无网络/模型入口，不改SQL结构。断网检查覆盖完整获准批次、路径与失败保护、任务范围和推荐；组件与SDK检查覆盖单图确认及分类传递，真实付费生成另行验收。
