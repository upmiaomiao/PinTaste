# Agent Note: PPT任务入口与共享预设

Status: implemented

[English](2026-11-06-ppt-task-entry.md) | 中文

## 问题

只追加建议文字的首页卡片不会改变已保存的页数和类型。上传的原稿可能因此被当作默认新建PPT的参考材料。新任务偏好也可能与历史重排项目的实际模式不一致。

## 决策

同一个会话偏好控制器服务任务入口、生成卡片和设置弹层。卡片保存生成类型及匹配页数，不修改草稿；两个任务入口区分新建与原稿重排。附件及绑定项目固定任务类型，另一任务由新对话承载。项目观察提供实际生效模式，不覆盖已保存的新任务默认值。

入口在发送前记录普通可读任务摘要。上传创建也将task_mode、creation_kind及页数传给既有MCP创建操作。原稿本地准备成功前，重排项目拒绝生成及阅读模型操作。第二版偏好读取展示新增字段，旧读取只展示三字段，旧保存保留任务选择。旧存储记录读时归一化，无需批量重写。

首页建议使用session-maybe插槽。会话项目状态句柄只挂载在Session插槽；可观察偏好快照与首页共享，避免把同一句柄挂在第二种作用域。

## 考虑过的替代方案

**追加更多提示词。** 可见设置与保存选择仍不一致。

**给卡片另建状态。** 新增一份可独立修改的页数及类型默认值。

**静默切换现有项目。** 可能混淆原稿与参考资料语义，或丢失已接受的逐页计划。

## 后果

内容语言和输出格式继续独立管理。模式选择不保存生成授权；重排保留原页、模板及最终图片校验。已有项目和原件不变，无SQL结构或历史数据迁移。

零密钥检查覆盖真实偏好HTTP处理器、实际MCP SDK创建调用、原页Worker回归、双语实际桌面组装、刷新及捕获的提交文字。包内期望文本固定新增模型摘要；完整框架类型检查仍受既有插槽/API声明漂移影响，430像素界面在原生响应式切换完成后验证。检查不使用真实模型或付费生成。
