# Agent Note: 工作输入窗口的整套 PPT 页数

Status: implemented

## Problem

工作请求需要可见且随消息保存的准确页数，选择页数本身不应开始生成。

## Decision

每个会话的输入窗口可选按文字需求或指定 1–80 页。1 页使用既有单页模式，不额外增加封面；2–80 页使用含封面的整套模式。发送时将选中数量写入普通用户消息。中间编辑值无效时，先阻止提交，再考虑既有搜索选项的授权；会话和插件卸载均移除共用的提交处理器。单图和少量页请求保留自己的范围。

## Alternatives considered

启用完整旧工具栏会额外暴露本轮范围外的模型和输出设置。修改后端默认数也无法表达用户的明确选择，因此通过现有提交扩展传递页数。

## Consequences

选择只在当前会话中保存，不改变后端流程，也不启动模型。既有助手通过当前项目接口保存要求，后端数量校验与用户审核仍有效。验证覆盖数量准入、非法输入、会话隔离、重试、组件输出、候选构建和真实工作台；提交内容在发往模型前拦截检查。
