# 专家反馈与完整问答数据

## 使用方式

系统管理 → 专家反馈，勾选“在问答界面开启专家反馈”并保存。功能默认关闭；关闭时普通问答界面不显示反馈入口，已保存数据不会删除。

管理员自动具有专家权限。管理员可以勾选指定专家账号；该资格不会改变账号角色，也不会授予系统管理或其他用户对话的访问权限。指定专家评审自己的问答，管理员可在管理页查看全平台问答。

已打开的问答页面在重新聚焦或 30 秒内同步管理员开关；刷新页面可立即同步。权限检查在服务器执行。

每轮生成结束后，“专家反馈”按钮位于回答下方网页、文献来源按钮之后；没有联网来源的问答也可评审。点击后在右侧栏填写意见，电脑端可同时对照左侧正文、展开思考过程或工具记录，左右分别滚动；窄屏显示抽屉，支持关闭按钮、遮罩和 Escape。反馈与来源面板共用右侧位置。

在侧栏选择问题位置、问题程度和评审结论，填写问题与不足说明、修改建议及可选的建议完整回答。关闭或切换来源面板后，未保存草稿在当前登录会话内保留，按账号和问答隔离；刷新页面或退出登录会清除草稿。语音按钮沿用当前 Qwen3.8 Omni 识别配置，先转写、再核对、最后保存；原始转写与核对后的意见都保留。录音原始音频不落盘。

点击字段右侧的麦克风后，录音提示在该字段标题下、输入框上方展开，自动滚动到可见位置，无需横向拖动。先显示“正在准备录音”，收到本地 PCM 后继续采集 0.6 秒，再显示“可以开始说话”。语音服务尚在连接时，开头音频在本地有界缓存，连接就绪后按顺序上传；连接失败明确提示重录，取消会释放麦克风并丢弃缓存。首次使用仍需先允许浏览器使用麦克风。单次录音保持原有时长限制，等待连接的缓存最多 10 秒。侧栏正文 15px，输入框及选项 16px，标题 20px；窄屏仍保持完整可见。

管理页可以查找问答、筛选有意见的记录，查看原始问题、模型回答、思考内容、工具记录及附件依据。反馈关闭时管理员仍可查看已有意见和导出。

## 保存规则

- 反馈维度包括问题理解、思考过程、推理逻辑、工具调用、证据与引用、最终回答。
- 存在不足时必须选择问题位置并填写修改建议。“可以采用”也需填写评审意见。
- 规则内容由管理员修改，产生独立规则版本；意见保存提交时的规则完整快照。
- 每次修改意见新增版本，保留专家身份、时间、前一个版本、原问答版本和内容摘要校验，不覆盖原回答或历史意见。
- 问答、规则或反馈版本变化时拒绝过期提交。刷新规则与记录后再保存，保留当前输入草稿。
- 语音记录绑定专家账号、对应问答和输入字段；不能把他人的录音或另一轮的转写关联到当前反馈。关闭反馈、关闭反馈语音或撤销资格后，后端也停止允许该用途的语音识别。

## 完整轨迹

所有新任务都保留执行记录，反馈开关控制界面和提交资格，不影响正常问答的数据归档。`job_events` 按顺序记录执行开始、附件检索、实际模型请求、流式内容、逐轮模型返回、工具规划与参数、工具结果、用量、警告或错误以及最终状态。

实际模型请求保存经过上下文预算调整后的请求体，包括模型实际看到的历史、问题和工具结果。记录不包含认证请求头、API 密钥或服务配置。工具完整返回与发给模型的压缩版本分别保留；工具调用前的模型反馈不再因界面切换到下一轮而丢失。

思考内容只记录模型接口实际返回的 `reasoning`、`reasoning_content` 或 `<think>` 内容，不推测接口未提供的内部思维。旧任务没有逐轮事件时标记 `legacy_partial`，保留现存思考、答案和工具记录，不声称可以恢复过去未保存的中间步骤。运行中或非正常结束的记录标记是否捕获完整。

## 导出

系统管理 → 数据导出，可导出全部用户或选定用户。问答侧栏“导出当前对话完整数据”下载当前对话的 JSON；原 Markdown 接口仍可使用。

JSON 格式 `wuyu-user-data` 版本 2 包含：

1. 用户资料、对话、每轮完整问题和最终回答、模型返回的思考内容、引用、RAG 原文依据、用量与任务状态。
2. 每轮 `execution_trace`：按顺序的实际模型输入、逐轮返回、工具参数与完整结果、错误及最终状态，并说明记录完整度。
3. 每轮 `expert_feedback`：全部反馈版本、专家身份、问题位置、结论、修改建议、建议回答、原始转写和当时的规则快照。
4. 独立规则版本、语音转写记录、对话记忆，以及勾选后包含的附件原件、全文、结构化页段和规范化图片。

当前对话导出只包含该对话及相关附件。专家对所选用户问答的意见随对应问答导出，专家身份作为相关记录的元数据保留。密码及散列、登录会话、验证码和 API 密钥不导出。导出使用一致的数据库快照，下载文件为私有临时文件，完成下载后清理。
